# Accessibility experience

Reduced Motion uses a stable Threshold Shot, material dissolves and light changes in place of travel. Essential mode retains the music, title, chapter, lyric, key description, photograph transition and slice conclusion in semantic HTML. The archive drawer provides stable lyrics and a description of current visual state. Controls have visible focus, 44px targets, Space/Enter support and TV-safe focus order. High contrast is available without color-only state. WebGL failure automatically selects the designed 2D paper-stage fallback.
