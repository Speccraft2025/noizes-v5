# Accessibility report

Implemented: semantic playback controls; visible focus; keyboard and TV-remote-compatible activation; touch targets; stable seeking; live lyric announcements; pinned high-contrast lyrics; reduced motion; system motion preference; volume and mute; non-3D Guide access; provenance and rights text; responsive mobile/desktop/TV layouts; no flashing; no information conveyed by motion alone.

Target: WCAG 2.2 AA. Known limitation: the manually authored LRC lines are reference-quality line synchronization, not phoneme-level timing. Formal screen-reader testing across VoiceOver, TalkBack, and television browsers remains an integration recommendation.
