# Spatial audio design

The Web Audio graph contains music, world, object, transition and master buses. The historical recording remains at unity gain. Original procedural wind is placed left/outside and low-pass filtered; structural resonance occupies the house centre. A short synthesized brass event belongs to the key position. During Photograph Entry, outside ambience is attenuated and filtered to imply occlusion.

All added audio is generated at runtime from noise and oscillator primitives, contains no external recording and is subordinate to the music. If Web Audio is unavailable, the HTML audio element remains a stereo-safe playback path.
