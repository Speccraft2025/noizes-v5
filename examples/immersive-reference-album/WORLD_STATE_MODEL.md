# World state model

Authoritative inputs are audio time, quality profile, accessibility preferences and persistent discoveries. Derived state includes object opening, camera rig, architectural recovery, material warmth, breath pressure, condensation, key recovery, photograph development, portal continuity and acoustic occlusion.

Every frame resolves these values from time. Ambient dust rotation may continue while paused; architecture, camera, materials, lyric, key and portal freeze. Seeking reduces to the latest cue and evaluates the same deterministic functions used during normal playback.
