# Testing

Run `./gradlew testDebugUnitTest assembleDebug`. Unit coverage begins with archive-path security, status separation, and explicit track ordering. The generated fixture contains manifest, experience, artwork, generated tone audio, credits, rights, edition, authenticity, technical data, and lyrics.

Manual TV acceptance: launch offline; select fixture folder; confirm scan state; open object using only D-pad; inspect validation; enter threshold and experience; use play/pause; exit; open native audio; seek; restart and confirm progress. Also import a renamed text file as `.nz` and confirm it shows `INVALID` without a crash.

Instrumentation coverage for the real system picker and emulator media keys remains to be added once a TV emulator is part of CI.
