# Transcendence V2 Gates

`transcendence-v1` remains the legacy runtime.

`transcendence-v2` is the clean-runtime rebuild path and is intentionally landscape-only at first.

## Gate A

Route:

- `/transcendence-v2`

Required validation shots:

1. `AERIAL`
2. `TROUGH`
3. `CREST`

Current scope:

- no lyrics
- no captions
- no subtitles
- no audio
- no NED
- no Studio bake path

The purpose of Gate A is to approve the new world grammar before analysis or authoring systems are reconnected.
